TrueType faces the port rebuilds both games' bitmap fonts from (`runtime/fonts.c`, NOTES.md "Native fonts"):
Barlow SemiBold (HUD, inventory), Barlow Medium (dialogue, subtitles), Oswald SemiBold (menu titles; the
weight-600 instance of Oswald's variable font, made with fontTools' instancer), Anton (FE2's title screen).
All from Google Fonts, licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).

The controls menu (`runtime/ui.c`): Special Elite (Fear Effect 1) and Barlow Condensed Bold / SemiBold
(Fear Effect 2), copied from the remaster's tools\fonts; Google Fonts. Barlow Condensed: SIL Open Font License 1.1;
Special Elite (Astigmatic): Apache License 2.0 (its own name table says so).
